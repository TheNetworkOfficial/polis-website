What Polis does today

Location-aware local feed

Users set a home area manually or opt into GPS to see relevant local content.

Posts, comments, and replies

Share image/video posts and discuss updates with thread-style conversations.

Events and signups

Create and join local events. Free event signup is available now.

Candidate access tools

Application, profile, dashboard, staff, messaging, donations, missions, and voter-map tools support campaigns where role access applies.

Coalition workspaces

Coalitions can manage members, missions, petitions, governance, amplification, rooms, and voter-map work.

Messaging workspace

Direct messages, requests, group chats, campaign rooms, coalition rooms, roles, pins, invites, and recovery tools are available from web.

Safety controls

In-app reporting, muting, blocking, and moderation workflows help protect the community.

Paid events

Paid event processing is not currently live in this release and is marked as coming soon.
